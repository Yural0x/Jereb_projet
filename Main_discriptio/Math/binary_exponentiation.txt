ШВИДКЕ ПІДНЕСЕННЯ ДО СТЕПЕНЯ (Binary Exponentiation) — принцип та реалізація
============================================================================

ЗАГАЛЬНА ІДЕЯ
-------------
Швидке піднесення до степеня обчислює a в степені n набагато швидше за наївне
множення в циклі. Замість n-1 множень воно використовує приблизно log n множень,
спираючись на розклад показника на степені двійки. Це критично, коли показник
величезний (наприклад, у криптографії), де лінійний підхід просто неможливий за
часом.

МАТЕМАТИЧНА ОСНОВА
------------------
Уся ідея тримається на двох рівностях:
- якщо показник парний: a^n = (a^(n/2))², тобто степінь можна порахувати,
  піднісши до квадрату результат для вдвічі меншого показника;
- якщо показник непарний: a^n = a · a^(n-1), і a^(n-1) уже має парний показник.
Багаторазово застосовуючи ці правила, ми щоразу приблизно вдвічі зменшуємо
показник, тому кількість кроків логарифмічна.

ДЕТАЛЬНИЙ ПРИНЦИП РОБОТИ — ІТЕРАТИВНА ВЕРСІЯ (по бітах показника)
----------------------------------------------------------------
Найпоширеніша реалізація обробляє показник по його двійкових бітах. Тримаємо два
значення: result (накопичений результат, спочатку 1) і base (поточна основа,
спочатку a). Поки показник більший за нуль:
- Дивимось на молодший біт показника. Якщо він дорівнює 1, домножаємо result на
  поточну base (цей біт "вмикає" відповідний степінь двійки у добуток).
- Підносимо base до квадрату (готуємо її до наступного, вищого біта — base тепер
  відповідає наступному степеню двійки).
- Зсуваємо показник на один біт вправо (ділимо на 2 націло), переходячи до
  наступного біта.
Коли показник вичерпано, у result лежить a^n. По суті, ми складаємо потрібний
степінь із "цеглинок" — степенів a, що відповідають степеням двійки (a, a², a⁴,
a⁸, ...), беручи лише ті, які присутні у двійковому розкладі n.

МОДУЛЬНИЙ ВАРІАНТ
-----------------
У більшості практичних застосувань (особливо в криптографії) обчислюють a^n за
модулем m. Тоді після кожного множення беремо остачу за модулем m. Це утримує
числа малими (не дає їм зростати безмежно) і дає той самий результат, бо операція
взяття модуля сумісна з множенням. Без цього кроку числа стали б астрономічно
великими.

УЗАГАЛЬНЕННЯ — ПІДНЕСЕННЯ МАТРИЦЬ
---------------------------------
Той самий алгоритм працює не лише для чисел, а для будь-якої операції, що є
асоціативною. Найважливіший випадок — піднесення квадратної матриці до степеня.
Це дозволяє за логарифмічний час обчислювати n-й член лінійних рекурент
(наприклад, чисел Фібоначчі через матрицю переходу) і моделювати багатократні
переходи в графах чи автоматах. Замість множення чисел використовуємо множення
матриць, а замість одиниці — одиничну матрицю.

ЧОМУ ВІН КОРЕКТНИЙ
------------------
Кожен біт показника відповідає певному степеню двійки. Двійковий розклад показника
єдиний, а наш алгоритм рівно один раз додає у добуток той степінь a, що відповідає
кожному встановленому біту. Тому добуток точно дорівнює a^n.

КЛЮЧОВІ МОМЕНТИ РЕАЛІЗАЦІЇ
--------------------------
- Ініціалізувати result нейтральним елементом (1 для чисел, одинична матриця для
  матриць).
- Не забути піднести base до квадрату на кожній ітерації, навіть коли біт нульовий.
- У модульному варіанті брати модуль після КОЖНОГО множення.
- Обробити крайові випадки: показник 0 дає 1; для від'ємних показників потрібна
  модульна обернена (через розширений Евклід).

СКЛАДНІСТЬ
----------
Час: O(log n). Пам'ять: O(1) для чисел (ітеративна версія). Для матриць час
множиться на вартість одного множення матриць.
