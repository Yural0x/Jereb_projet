Степінь за модулем

Обмеження: 1 сек., 256 МіБ

Складність: легка

Обчисліть a у степені n за модулем 1000000007. Показник може бути дуже великим, тож звичайне множення в циклі не підійде.

Вхідні дані

У єдиному рядку — два числа a і n.

Вихідні дані

Значення an mod 1000000007.

Обмеження

0 ≤ a ≤ 109; 0 ≤ n ≤ 1018.

Приклади

Вхідні дані (stdin) Вихідні дані (stdout)
2 101024
Вхідні дані (stdin) Вихідні дані (stdout)
3 01

Примітки

2 у степені 10 = 1024.

Будь-яке число у степені 0 дорівнює 1.
