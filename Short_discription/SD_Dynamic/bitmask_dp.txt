ДП НА БІТОВИХ МАСКАХ (Bitmask Dynamic Programming)
==================================================

ДЕ ВИКОРИСТОВУЄТЬСЯ В РЕАЛЬНИХ ПРОЕКТАХ
---------------------------------------
- Оптимізаційні задачі з невеликою кількістю об'єктів, де треба перебрати всі
  підмножини: розподіл задач між виконавцями, планування з обмеженнями.
- Логістика й маршрутизація: задача комівояжера (TSP) на невеликому числі міст —
  точний розв'язок через DP по підмножинах відвіданих міст.
- Планування та призначення (assignment): оптимальне зіставлення N об'єктів N
  позиціям з мінімальною вартістю.
- Задачі покриття множин і компактного кодування станів.

ТИПОВІ ЗАДАЧІ
-------------
- Задача комівояжера (TSP) для малих N (зазвичай N <= 20).
- Оптимальне призначення / парування з вартостями.
- Підрахунок або оптимізація над усіма підмножинами набору.

ЯК ПРАЦЮЄ
---------
Стан задачі кодуємо цілим числом, де кожен біт означає "об'єкт включений /
відвіданий чи ні" (маска підмножини). Наприклад, для TSP стан — це (маска
відвіданих міст, поточне місто). Переходи між станами реалізуємо через бітові
операції (встановлення/перевірка бітів). Перебираючи всі можливі маски та
переходи, заповнюємо таблицю DP. Метод працює лише для малих N, бо кількість
підмножин — 2^N, тобто росте експоненційно.

ЧАСОВА СКЛАДНІСТЬ
-----------------
Залежить від задачі; для TSP: O(2^N * N^2)
Загалом: O(2^N * (вартість переходу))
Пам'ять: O(2^N * N)
Обмеження: практично застосовне лише для малих N (приблизно до 20)
